# Research

For all our mix dependencies, compare the latest and installed version.
For each version that is not up-to-date, read the changelog between the 2 versions.

Check in the codebase if there are any regressions, changes or cleanup necessary. Include cleanups and simplifications that can be made because a new feature or API is available in the lib.

Present a recap table of all the updates to be made, the main changes, and the impact in our codebase (if any).

Ask user validation before performing the update.
